# كـويـز — اختبار إلكتروني ذاتي التصحيح

مشروع كليوي تفاعلي باللغة العربية (RTL) لاختبار الطلبة في **أساسيات الكمبيوتر**. يعمل كصفحة ويب ثابتة بدون أي backend أو قاعدة بيانات أو مكتبات خارجية — يكفي رفع الملفات على أي استضافة مجانية.

## المميزات

- **تصحيح فوري** بعد التسليم مع درجة مئوية وتقدير (ممتاز / جيد جداً / …).
- **مؤقت ذكي** حسب عدد الأسئلة، مع تحذير عند آخر دقيقة وتسليم تلقائي عند انتهاء الوقت.
- **ترتيب عشوائي** للأسئلة في كل محاولة.
- **خريطة الأسئلة** للتنقل السريع مع تمييز: مُجاب / حالي / للمراجعة / لم يُجب.
- **تحديد للمراجعة** (عَلم 🚩) لأي سؤال.
- **مراجعة مفصّلة**: إجابتك + الإجابة الصحيحة + شرح كل سؤال، مع فلترة (الكل / الصحيحة / الخاطئة).
- **شهادة درجة قابلة للطباعة** أو الحفظ كـ PDF.
- **حفظ النتائج** آخر 8 محاولات في المتصفح (localStorage).
- **لوحة مدرس** للإحصائيات وتوزيع التقديرات وجدول النتائج وتصدير CSV.
- **مزامنة اختيارية** مع Supabase عشان الدكتور يشوف درجات كل الطلبة في مكان واحد (`BACKEND.md`).
- **استئناف المحاولة** بعد إغلاق الصفحة أو تحديثها.
- **اختصارات لوحة المفاتيح**: `1–4` للاختيار، `← →` للتنقل.
- تصميم متجاوب للجوال والتابلت، وخفيف جداً (بدون إنترنت بعد التحميل).

## الملفات

```
quiz-app/

├── js/questions.js     # بنك الأسئلة (24 سؤالاً قابلاً للتعديل)
├── js/config.js        # إعداد Supabase الاختياري
├── js/cloud.js         # طبقة الإرسال/القراءة من Supabase
```

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم بسيط:

```bash
cd quiz-app
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## تعديل الأسئلة

عدّل الملف `js/questions.js`. كل سؤال عبارة عن كائن:

```js
{
  id: 25,                       // رقم فريد
  category: "أساسيات",          // أساسيات / إنترنت / أمان
  text: "نص السؤال؟",
  options: ["أ", "ب", "ج", "د"], // 4 إجابات بالترتيب
  answer: 0,                    // فهرس الإجابة الصحيحة (يبدأ من 0)
  explanation: "سبب الإجابة..."
}
```

الاختبار يسحب عشوائياً عدد الأسئلة المختار من الشاشة الأولى (10 / 15 / 20).
